# StudyForge

StudyForge — локальное desktop-приложение для организации, просмотра, обработки и поиска по учебным материалам.

Приложение работает поверх обычной файловой системы пользователя. Пользователь выбирает папку на компьютере как рабочее пространство, а StudyForge отображает её содержимое в виде дерева файлов и предоставляет инструменты для просмотра, редактирования, поиска и обработки материалов.

Все исходные материалы остаются обычными файлами на компьютере и не зависят от StudyForge.

Пример рабочего пространства:

```text
Учёба/
├── Базы данных/
│   ├── notes.md
│   ├── Лекции/
│   │   ├── lecture_01.pdf
│   │   └── lecture_02.pptx
│   ├── Лабораторные/
│   │   └── lab01/
│   │       ├── report.md
│   │       └── query.sql
│   └── materials.xlsx
│
├── Электротехника/
│   ├── notes.md
│   └── lecture.pdf
│
└── Программная инженерия/
    ├── notes.md
    └── lecture.m4a
```

## Основные принципы

- пользовательские материалы хранятся в обычных папках и файлах;
- StudyForge не является обязательным для доступа к этим данным;
- пользователь сам выбирает рабочую папку;
- рабочее пространство можно сменить в любой момент;
- структура папок отображается непосредственно из файловой системы;
- материалы можно просматривать прямо внутри StudyForge;
- текстовые и Markdown-файлы можно редактировать;
- остальные учебные форматы в первую очередь доступны в режиме просмотра;
- служебные индексы и кэш должны быть полностью восстанавливаемыми;
- удаление приложения не должно приводить к удалению учебных материалов.

# Поддерживаемые форматы

Планируется поддержка следующих типов файлов:

| Формат | Просмотр | Редактирование |
| --- | --- | --- |
| Markdown `.md` | Да | Да |
| Text `.txt` | Да | Да |
| PDF `.pdf` | Да | Нет |
| Word `.docx` | Да | Нет |
| Excel `.xlsx` | Да | Нет |
| CSV `.csv` | Да | Нет |
| PowerPoint `.pptx` | Да | Нет |
| PNG/JPG/JPEG | Да | Нет |
| MP3/WAV/M4A | Да, через аудиоплеер | Нет |

Для неподдерживаемых файлов должна оставаться возможность открыть файл внешней программой операционной системы.

# Архитектура интерфейса

Основное окно разделено на две части:

```text
┌────────────────────────┬────────────────────────────────────┐
│ Файловое дерево        │ Просмотр / редактор                │
│                        │                                    │
│ ▾ Базы данных          │                                    │
│   ▾ Лекции             │     содержимое выбранного файла    │
│     lecture.pdf        │                                    │
│   notes.md             │                                    │
│                        │                                    │
└────────────────────────┴────────────────────────────────────┘
```

Левая часть предназначена для навигации по реальной файловой системе рабочего пространства.

Правая часть используется как встроенный просмотрщик или редактор выбранного файла.

Для переключения между различными просмотрщиками планируется использовать `QStackedWidget`.

Пример:

```text
QStackedWidget
├── стартовая страница
├── текстовый редактор
├── Markdown-редактор
├── PDF viewer
├── image viewer
├── DOCX viewer
├── spreadsheet viewer
├── presentation viewer
├── audio player
└── страница неподдерживаемого формата
```

# Финальный сценарий StudyForge

Пользователь выбирает папку с учебными материалами.

StudyForge отображает её структуру слева.

Пользователь может:

- раскрывать папки;
- выбирать материалы;
- читать PDF внутри приложения;
- просматривать DOCX;
- просматривать презентации;
- просматривать таблицы;
- просматривать изображения;
- слушать аудиолекции;
- редактировать Markdown и TXT;
- вести общий конспект;
- искать информацию одновременно по разным форматам;
- распознавать изображения;
- получать транскрипции аудиолекций;
- создавать Markdown-отчёты;
- проверять отчёты на соответствие требованиям;
- экспортировать их в DOCX/PDF.

При этом исходные данные продолжают существовать как обычные файлы и папки независимо от StudyForge.
