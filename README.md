# StudyForge

StudyForge — локальное desktop-приложение для организации и обработки учебных материалов.

Программа позволит хранить материалы по предметам, выполнять единый поиск по содержимому файлов, преобразовывать изображения и аудиозаписи лекций в текст, вести общий редактируемый конспект по каждому предмету и автоматически собирать оформленные отчёты из Markdown.

## Основные функции

- хранение учебных материалов по предметам;
- поддержка PDF, DOCX, PPTX, TXT и Markdown;
- единый полнотекстовый поиск по всем материалам;
- автоматический конспект по каждому предмету с возможностью ручного редактирования;
- распознавание текста с изображений и сканов;
- преобразование аудиозаписей лекций в текст;
- Markdown-редактор отчётов;
- автоматическое преобразование Markdown в оформленный DOCX/PDF;
- проверка отчёта на соответствие заданным требованиям.
