# StudyForge

StudyForge — локальное desktop-приложение для организации и обработки учебных материалов.

Приложение работает с обычной папкой на компьютере как с рабочим пространством. Пользователь выбирает папку, внутри которой находятся папки предметов, конспекты и остальные материалы. Все пользовательские файлы остаются обычными файлами и доступны через Проводник независимо от StudyForge.

Пример рабочего пространства:

```text
Учёба/
├── Базы данных/
│   ├── notes.md
│   ├── Лекции/
│   ├── Лабораторные/
│   └── Фото/
│
├── Электротехника/
│   ├── notes.md
│   └── Материалы/
│
└── Программная инженерия/
    ├── notes.md
    └── Материалы/
```

StudyForge будет использовать эту структуру для отображения предметов, поиска по материалам, формирования конспектов, распознавания изображений и аудио и подготовки отчётов.

## Основные принципы

- пользовательские данные хранятся в обычных папках и файлах;
- StudyForge не является обязательным для доступа к материалам;
- каждый предмет представляет собой отдельную папку;
- общий конспект предмета хранится в `notes.md`;
- рабочее пространство можно заменить другой папкой;
- служебные индексы и кэш должны быть восстанавливаемыми;
- удаление StudyForge не должно приводить к потере учебных материалов.
